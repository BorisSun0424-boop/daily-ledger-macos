# 营销与上架资料

每个产品版本使用单独目录，例如 `v1.0/`。在对应目录内区分宣传素材和商店上架资料，并明确标注草稿、已确认或已发布状态。

建议按需要保存：

- 宣传主题、受众与核心卖点
- 宣传文案、短视频脚本、社交媒体文案及配图
- 商店名称、副标题、简介、关键词与分类
- 截图、预览视频、图标及其他商店素材
- 发布渠道、发布日期与版本说明
- 最终提交/发布材料及其状态
