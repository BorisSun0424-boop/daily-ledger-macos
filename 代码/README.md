# 产品代码与资产

在此保存日常记账 App 的产品源代码和开发资产。

## 当前项目

- `DailyLedger/`：macOS 原生 SwiftUI App 源代码与测试。
- `开发计划.md`：依据 V0.1 PRD 制定的分阶段开发与测试计划。

建议后续按实际需要建立子目录，例如：

- `app/`：应用或网站源代码。
- `design/`：界面设计稿、图标与设计规范。
- `assets/`：产品使用的图片、音频、视频等资源。
- `scripts/`：构建、迁移或维护脚本。

## 项目说明模板

项目开发过程中在此补充：

- 产品名称与当前版本
- 技术栈及主要依赖
- 本地运行、构建与验证方式
- 目录说明
- 资产来源、授权和使用限制
