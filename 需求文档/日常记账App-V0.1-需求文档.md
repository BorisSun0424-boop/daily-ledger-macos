# 日常记账 App｜V0.1 需求文档

**状态：已确认**  
**确认日期：2026-10-18**  
**目标平台：macOS 原生桌面 App**  
**使用范围：仅供用户本人在自己的 Mac 上安装和使用**

## 1. 产品定位

一款只供用户个人使用的 Mac 原生记账 App。用户通过手动记录收支、管理账户余额和查看月度分类统计，了解钱花在哪里；App 使用温和的预算提醒，帮助用户减少不必要的消费。

## 2. 目标用户与使用场景

### 目标用户

- 用户本人。
- 不需要支持家庭成员、团队或其他共同记账者。

### 主要场景

- 日常手动记录一笔支出或收入。
- 查看现金、银行卡、微信、支付宝等账户的余额。
- 按月份回顾收入、支出和结余。
- 查看各类生活开支的金额与占比。
- 通过月度预算了解本月还能花多少钱。

## 3. 产品原则

- 本机离线运行，不依赖网络。
- 不注册、不登录、不部署服务器。
- 数据仅保存在本机。
- 录入过程简单，统计结果容易理解。
- 预算反馈保持温和，不使用惩罚、评分或带羞辱感的文案。

## 4. 核心使用流程

1. 首次使用时创建现金、银行卡、微信、支付宝等账户，并填写初始余额。
2. 日常手动新增一笔支出或收入。
3. 填写金额、分类、账户和日期，可选择填写备注。
4. App 自动更新相关账户余额。
5. 用户在月度统计页查看收入、支出、结余和分类分布。
6. 用户设置每月总预算，查看已花金额、剩余预算及本月剩余天数。

## 5. 功能需求

### 5.1 收支记录

- 支持新增、编辑和删除支出记录。
- 支持新增、编辑和删除收入记录。
- 每笔记录包含：
  - 金额
  - 收支类型
  - 分类
  - 账户
  - 日期
  - 备注（选填）
- 支持按月份查看历史账目。

### 5.2 账户管理

- 支持创建、编辑和停用账户。
- 支持为账户设置初始余额。
- 支持查看单个账户与全部账户的当前余额。
- 支持账户之间转账。
- 转账只改变相关账户余额，不计入收入或支出统计。

### 5.3 分类管理

- 提供系统预设的支出和收入分类。
- 支持新增、重命名和调整分类。
- 已经被账目使用的分类不能直接删除；删除前需要把历史账目转移到其他分类。

#### 预设支出分类

- 餐饮
- 交通
- 购物
- 居住
- 娱乐
- 医疗
- 学习
- 人情
- 其他

#### 预设收入分类

- 工资
- 兼职
- 理财
- 红包
- 其他

### 5.4 月度统计

- 展示本月总收入。
- 展示本月总支出。
- 展示本月结余。
- 展示各支出分类的金额和占比。
- 展示本月总支出与上个月的对比。
- 展示本月支出金额最高的三个分类。
- 支持切换并查看已有账目的历史月份。

### 5.5 月度预算

- 支持设置每月总支出预算。
- 展示本月预算总额。
- 展示本月已经支出的金额。
- 展示剩余可用预算。
- 展示本月剩余天数。
- 接近预算或超过预算时，在 App 内提供温和提醒。
- 超过预算后显示具体超出金额。

## 6. 首版不包含

- 注册和登录。
- 联网或服务器。
- 云同步和多设备同步。
- 多人或家庭共享账本。
- 银行账单自动导入。
- OCR 小票识别。
- 凭证图片。
- 分类独立预算。
- 多币种。
- 投资资产和负债管理。
- 自动生成周期账单。
- 数据导出与备份。

## 7. 验收标准

- [ ] 在断网状态下可以完成全部产品操作。
- [ ] App 不要求注册或登录。
- [ ] App 不会向网络发送记账数据。
- [ ] 关闭并重新打开 App 后，账目、账户、分类和预算仍然存在。
- [ ] 可以新增、编辑和删除收入或支出记录。
- [ ] 新增、编辑或删除账目后，相关账户余额会正确更新。
- [ ] 新增、编辑或删除账目后，对应月份的统计会正确更新。
- [ ] 账户转账只改变两个账户的余额，不影响月度收入和支出。
- [ ] 可以查看任意已有账目月份的明细和统计。
- [ ] 月度统计正确展示收入、支出、结余、分类金额、分类占比、上月对比和支出前三分类。
- [ ] 可以设置月度总预算，并正确显示已花金额、剩余预算和本月剩余天数。
- [ ] 月度支出超过预算后，App 能正确显示超出金额。
- [ ] 系统预设分类可以正常使用，用户也可以新增和重命名分类。
- [ ] 已被账目使用的分类不能在未处理历史账目的情况下直接删除。

## 8. 数据与技术约束

- 运行平台为 macOS。
- 使用原生桌面 App 形态。
- 所有产品数据保存在本机。
- 首版使用单一币种；具体币种显示在设计阶段按人民币处理。
- 不建设网络接口、用户系统或云端数据库。

## 9. 风险与后续观察

- 账户余额依赖初始余额和每笔账目的准确性，需要让修改与删除后的余额可验证。
- 预算提醒需要保持有帮助且不过度打扰，具体文案和触发位置在界面设计阶段确认。
- 首版不包含备份与导出，本机数据丢失后的恢复能力有限；后续版本可根据实际使用需要再评估。
