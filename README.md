# 产品资料库

本文件夹用于保存这个产品从需求对齐、开发到发布的资料。

## 资料归档规则

- 每次与用户对齐的需求，按版本记录在 `需求文档/`。记录范围以双方明确确认的内容为准，并保留历史版本，不用新版本覆盖旧版本。
- 产品源代码、设计稿、图片、音频、字体及其他交付资产放在 `代码/` 中。按平台、模块或资源类型建立子目录，并保留必要的来源和使用说明。
- 每个产品版本的宣传内容与上架资料放在 `营销文档/`，按版本建立独立子目录。
- 文件名尽量包含版本号、主题和日期；草稿与已确认/已发布材料应明确标注状态。

## 目录

- `需求文档/`：需求版本记录与需求模板。
- `代码/`：产品代码、设计与媒体资产及其说明。
- `营销文档/`：各版本宣传资料、商店上架文案和发布信息。

## 新版本建议流程

1. 对齐需求后，在 `需求文档/` 新建一个版本记录，写明目标、范围、排除项和验收标准。
2. 开发过程中，将代码和资产归入 `代码/`，并在该目录的说明中更新项目入口与运行方式。
3. 准备宣传或上架时，在 `营销文档/` 建立对应版本目录，分别保存草稿与最终材料。
